# Vocabulary data attribution

This project incorporates a filtered and corrected subset of the Spanish frequency list sourced from:

- **Hermit Dave**, [FrequencyWords](https://github.com/hermitdave/FrequencyWords), `content/2018/es/es_50k.txt`.
- Based on OpenSubtitles2018 text corpora.
- **[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/)** applies to the source list's **content**. The upstream MIT licence separately covers its **code**.

**Changes:** Added 576 nine-letter forms from the higher-frequency portion of the source list to the original 24 manual Auto seeds; excluded names and other unsuitable/noisy entries; corrected selected spelling and accent errors; deduplicated accent-equivalent spellings; combined with the existing educational lexicon and ranked the resulting local entries for word length and variety.

The frequency-derived vocabulary subset is shared under **CC BY-SA 4.0**. This attribution does not replace or alter any separate licensing of the original game's code or artwork.

Frequency rank is not a formal CEFR classification; these forms have not all been checked individually in an authoritative Spanish dictionary. Teachers should review suitability for their class.
